# Calculation Data

这个文件夹用于保存用户主动生成的有限元计算输入和结果 TXT，不再承担默认计算的数据中转。

计算页“开始计算”默认通过 Node.js/C++ 二进制管道直接传输模型与结果，不会改写本文件夹。开启“输出设置 → 额外生成计算 TXT”后，计算时才会在这里创建或覆盖 `calculation-input.txt` 和 `calculation-result.txt`。

点击“导出计算文件”也会单独创建或覆盖 `calculation-input.txt`，不需要先运行求解。

这个文本文件只保存后续 C++ 求解器需要的最小输入：连续编号后的节点、单元、材料力学参数、边界约束、全局节点载荷和单元等效节点载荷。

可选的 `calculation-result.txt` 保存节点位移、单元应变、单元应力和单元安全校核结果，便于人工检查和外部程序交换；计算结果页正常情况下直接使用内存中的结构化结果。

推荐通过项目根目录的 `启动程序.bat` 打开程序。启动器会先启动本地服务，再自动打开浏览器页面，使前端能够直接运行 C++ 核心。

不推荐直接双击 `index.html`。本地 HTML 会受到浏览器安全限制，不能稳定写入项目文件夹，也不能自动运行 C++ 计算核心。
