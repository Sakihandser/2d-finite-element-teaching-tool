# 线弹性自适应网格

在计算页勾选 **自适应网格（ZZ）**，设置细化轮数和目标相对误差，然后点击 **开始计算**。默认最多细化 6 次（包含初始网格最多求解 7 次），目标为 0.02，即 2%。开启后禁用并忽略普通网格的节点上限；自适应细化不限制节点总数。未勾选时使用单次求解和普通节点上限，默认上限为 20000 个节点。

计算设置中的 **使用 GPU 加速** 默认关闭；开启时提醒建议单元超过 200 万个再打开。每次计算开始时记录该选择，整个自适应过程沿用同一设置；无兼容 GPU 时自动回退 CPU。

勾选 **自适应网格（ZZ）** 时提示：建议用于裂纹与应力集中研究；若非专门研究此类问题，不建议使用，建议优先采用均匀网格。

勾选自适应模式时，清空当前计算节点和网格，并重新布置基础节点。点击 **开始计算** 时也从新基础网格开始，使用 Triangle 约束剖分；初始布点以约 1000 个节点为密度参考，并保留几何特征、孔洞边界和载荷锚点。这不是自适应网格的节点总数上限，普通节点上限不影响该基础网格。

点击 **迭代加密一次**，在当前有效网格上先求解并估计 ZZ 误差，再加密一轮并重新求解，不清空节点和网格。可连续点击，也可在未勾选自适应模式时使用；该按钮不受目标误差和细化轮数设置限制，但仍遵守局部尺寸保护。没有有效网格或网格已过期时提示先生成网格。

自适应网格会写入当前模型，可继续查看结果、导出计算输入或保存 JSON。每轮重新从几何模型组装材料、支撑、点载荷、线性分布载荷和体力；最终结果对应最后一次成功求解的网格。若下一轮求解失败，恢复上一张已求解网格。计算过程中修改几何、材料或载荷会中止该流程，需要重新计算。

约束网格单元的区域归属沿用 Triangle 的区域属性及细化时继承的标记，材料参数仍从当前区域刷新。这样可避免孔洞附近的小单元被质心容差误判为空气，或被重新分配到材料接口另一侧。自适应求解前检查材料和面积；参数缺失或应力结果无效时，提示具体单元及相关区域。

勾选自适应网格后，可在“单轮最长耗时（秒）”中设置停止加密的耗时上限，默认 10 秒，支持 0.1–2147483 秒。自动迭代和 **迭代加密一次** 均使用此设置。一轮的输入准备、求解、误差估计及加密累计耗时达到设置上限时，不继续提交加密网格。若本轮求解成功则保留其结果；若 C++ 求解超过设置上限，则终止该进程并恢复上一张已成功求解的网格。没有成功结果的首轮超时会明确报错。加密及连接优化在独立 Web Worker 中执行，超过设置上限会终止该 Worker，保留当前已求解网格；均匀网格作为停止提示中的建议，由用户选择是否重新布点和划分。普通单次计算仍沿用原来的 120 秒核心超时。历史记录保存每轮耗时及触发保护的原因。

## 从 MFEM 4.10 移植的内容

实现文件：`src/core/adaptive-mesh.js`。

依据下载源码中的 `examples/ex21.cpp`，以及 `fem/gridfunc.cpp` 的 `ComputeFlux`、`ZZErrorEstimator`，`fem/bilininteg.cpp` 的 `ElasticityIntegrator::ComputeFluxEnergy`，`mesh/mesh_operators.cpp` 的 `ThresholdRefiner`。保留原例程、相关函数摘录和 BSD 许可证在 `mfem-4.10/`，供对照；摘录是参考源码，不能独立编译成 MFEM 库。

- 沿用“求解 → 恢复应力 → 计算误差 → 标记 → 细化”的循环。
- TRI3 单元应力在节点处按相邻单元数取算术平均，与 MFEM 的节点通量平均一致。按材料和区域分开恢复，避免抹平材料界面的应力跳跃。
- 用三个二次精度积分点计算恢复应力与单元应力差的能量，得到单元指标 `eta_K`。
- 使用现有求解器的**平面应力**本构和单位厚度：能量密度为 `(sx² + sy² - 2 nu sx sy + 2(1+nu) txy²)/(2E)`。不直接套用 MFEM 原例程的 Lamé 参数。
- 改用累计误差标记：按单元误差平方排序，选择累计标记权重达到 50% 的单元。选择权重对超过第 90 百分位四倍的极端值做截断，避免单个集中力点吞掉所有加密机会；原始 ZZ 指标和显示的相对误差不做截断。每个结构区域另选最多约 5% 的最大粗单元，逐步改善粗背景网格。
- 集中力周围增加连续尺寸场，中心目标面积为初始中位面积的 1/1024，在半径 `2 sqrt(baseArea)` 内按 `(1 + 3 distance/radius)^2` 平滑增大，最大为 1/64。即使中心单元的恢复误差很低，也会主动细化到尺寸目标，避免只追踪外围误差形成密环。多集中力采用最近锚点；原有锚点保持不动。
- 相对误差定义为 `sqrt(sum(eta_K²) / sum(element strain energy))`。零应力、零误差时返回 0。
- 标记单元先生成局部中点和相容过渡网格，再交给普通网格使用的同一个 Triangle WASM 引擎，以 `rpzq20YYQ` 重新连接并改善质量。输入含全部 TRI3 单元、区域/材料属性和约束边；Triangle 可以增加质量改进节点，原有节点顺序与集中力锚点保持不变。区域和孔洞面积、材料接口、边界标记均校验或保留。`YY` 保留这一轮已细分的约束边，避免跨区域不一致地新增接口节点。
- 初始网格和每轮细化后执行局部连接优化：对内部共享边组成的凸四边形尝试换对角线，只接受能严格提高两个三角形最小角度的连接。边界边、孔洞边、几何约束边和材料/区域界面不能换边。新连接会重新计算面积、质心、边界参数、质量及节点状态，随后重新组装并求解；不沿用父单元应力。
- 保留边界的 `curveId` 和 `tRange`，细分参数区间，使线性分布载荷继续积分。边界中点通过来源曲线继承固定支撑。
- 新节点位移用端点平均值插值，供显示使用；原 C++ 求解器仍在每轮重新求解，不使用该位移作为迭代初值。

## 停止和局限

正常计算根据目标误差和细化轮数停止，不检查普通节点上限。达到局部最小尺寸的单元只跳过，不中止其他区域的细化。集中力范围内的最小面积随尺寸目标变化，采用目标面积的 1/4；范围外以连续指数函数逐步过渡到全局局部下限（初始中位面积的 1/4096），均不低于现有网格解析精度 1e-10，不再使用中心较粗、外围突然变细的径向开关。背景网格改善到初始中位面积的一半后，不再为了背景规则继续均匀加密。这些尺寸保护随模型保存，继续计算时保持不变。连接版本升级为 4，旧自适应网格重建基础网格，清除旧环状节点分布。没有剩余可细化单元时明确报告局部尺寸限制；退化网格或求解失败仍回退到最后成功求解的网格。达到轮数或尺寸限制不表示达到目标误差。

Triangle WASM 原来固定为 16 MiB 内存，现在从 16 MiB 起按需增长，最大为 2 GiB 的运行时地址空间；这不是网格节点上限。内存增长后重新获取 IO 结构视图，并在完成或失败时释放输入、输出和参数。`scripts/patch-triangle-memory.cjs` 可重复应用此适配，只调整 WASM 导入内存的限制和 JavaScript 包装，不改变 Triangle 计算指令。

网格元数据 `adaptive.history` 保存每轮规模、原始 ZZ 误差、被跳过的饱和单元数量、标记策略和网格质量。集中力点的应力峰值具有网格敏感性；本算法不将峰值随加密增大误判为其他区域必须停止细化，也不将截断后的标记权重冒充精度达标。

连接优化保持节点坐标和边界折线不动；不能消除由极窄几何、受保护的短边或不良节点分布本身造成的所有小角度。窄椭圆孔测试验证有限宽度缺口的应力集中，不等同于零宽裂纹的断裂力学验证，也没有将某个最大单元应力认定为解析解。

ZZ 是误差估计，并非真实误差的保证。很粗的网格、单个单元区域、点载荷和支撑端点奇异性会影响估计或收敛。该实现只适用于二维、线性、各向同性、单位厚度的平面应力 TRI3 模型，不提供网格粗化、四边形、三维、高阶或非线性分析。

曲线边界仍使用初始网格的折线近似，细化中点保持在原边上，保持区域面积和载荷积分域不变；本功能不估计或降低曲线几何近似误差。

## 验证

运行：`node-v24.21.0-win-x64/node.exe --test tests/*.test.js`。

新增验证覆盖共享边连接、反复局部细化、两条分割边的闭合、正面积、区域保留、忽略节点上限、初始粗网格与普通节点设置解耦、旧网格迁移、精确 ZZ 积分、材料跳跃隔离、分布载荷守恒，以及最终网格求解和失败回退。真实 C++ 悬臂梁测试中，三轮局部细化使单元数从 32 增至 137，ZZ 相对估计误差从 66.90% 降至 32.46%；该测试采用端点集中力，不声称消除了奇异性或已达到 5% 目标。

`tests/adaptive-crack.test.js` 用长半轴 3、短半轴 0.15 的椭圆孔，在 10×10 板上施加单位顶部拉力，底边固定。五轮细化后，Triangle 混合连接的最小角度为 15.95°，旧固定连接为 2.27°。C++ 计算的最大拉应力位于孔端，并高于远场拉力。测试检查结构面积和载荷合力不变、孔边界闭合、内部边使用次数，以及多材料接口两侧的面积和节点一致性。增加集中力的回归模型连续完成八轮：距载荷锚点超过 2 的节点从 170 增至 6473，中心与外围单元中位面积分别约为 1.22e-4 和 9.77e-4，中心约密 8 倍，未因局部小单元提前中止。另验证中心恢复误差为零时仍主动加密，以及 320000 单元实际剖分中内存增长后原有 IO 数据有效。回归模型并非截图对应的原始模型。

Triangle 官方的[既有网格细化说明](https://www.cs.cmu.edu/~quake/triangle.refine.html)介绍了 `r` 模式及保留约束边的 `p` 模式；[参数说明](https://www.cs.cmu.edu/~quake/triangle.switch.html)解释了质量约束及 `YY` 的约束边保护。
