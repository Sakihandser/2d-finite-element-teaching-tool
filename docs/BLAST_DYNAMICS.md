# 爆破瞬态分析

本功能在 main 的现有二维 TRI3 网格上求解爆破引起的应力波和材料响应，按单位厚度计算。小变形可选择平面应力或平面应变，有限变形目前限于平面应变。可选拉伸损伤、线弹性、DP + 拉伸损伤和 JH2；详见 [岩石本构接口](ROCK_CONSTITUTIVE.md)。裂纹由连续损伤带表示，节点不会分离。基础静力模块的平面应力假设不随爆破设置改变。

## 使用

1. 启动本项目 `计算力学程序.exe`（或使用 `start.bat` 调试），展开顶部右侧“专业计算”，勾选“爆破模拟”。初次使用默认只有基础静力学功能；选择会保存在当前浏览器中。
2. 在“结构绘制”页创建或导入自己的模型，将炮孔设为圆形外部空气区域，并为结构分配材料、设置外载荷；在“材料库”编辑材料参数，然后打开“爆破设置”页。
3. 可直接使用基础“计算”页生成的有效均匀网格或自适应网格，也可在右侧“网格准备”生成普通网格。设置装药半径（可小于炮孔半径）、中心，并选择材料气体模型或给定孔壁压力时程，再设置围压、边界和时间积分，点击“运行爆破模拟”。程序会识别该中心对应的实际孔壁半径；也可先点击“识别并填入炮孔”查看。没有有效网格时程序会自动生成普通网格，调用 C++ 核心并进入独立的“爆破结果”页。时间步填 0 时自动选择。
4. 拖动“爆破时间帧”或点击“播放 / 暂停”，查看应力、应变、位移和损伤云图。“导出爆破表格与云图（ZIP）”流式下载标准 ZIP，包含全部保存帧的节点与单元 CSV、时程汇总、当前选中帧各分量 SVG 云图以及模型与参数。解压后用浏览器打开 `index.html` 查看目录和云图，用 Excel / WPS 打开 CSV。“导出当前类型云图（PNG）”另存 2400 × 1500 的图片 ZIP，应力和应变模式分别包含各分量及等效值。云图包含单位、色标与物理时间，采用原始网格；各帧独立色标，比较时间变化时应对照数值。旧 `/download` JSON/GZip 接口保留供程序兼容。
5. 深层岩石截面可选择“平面应变（深部截面）”，输入正值水平/竖直围压，选“先静力平衡，再保持外载荷”，并按需要选择外边界吸收条件。已有点力、分布力、体力会同时参与计算；不要把同一围压在快捷字段和分布力中重复施加。

基础工作台保留 v1.1.2 的四个主页面和静力学结果模式。爆破设置不再占用“计算”侧栏；基础“计算结果”和“爆破结果”各自保留结果数据、视图与变形倍数。取消勾选“爆破模拟”会隐藏两个爆破页签、停止回放并取消进行中的爆破求解；保留当前模型、参数及已完成的历史，重新勾选可继续查看。专业选择属于浏览器偏好，不随模型 JSON 自动启用；刷新页面仍需重新运行才有爆破历史。


## 网格复用与炮孔检查

基础计算和爆破共用 `scene.analysisNodes` 与 `scene.mesh`。运行爆破时显式传入 `adaptive:false` 表示不启动静力自适应迭代；它不会丢弃已有的有效自适应网格。只有网格缺失、已过期或格式版本过旧时才重新生成普通网格。“生成 / 更新网格”按钮则主动重新生成普通网格，会替换当前网格。右侧会显示当前普通/自适应网格能否直接使用。

静力 ZZ 自适应估计的是静力误差，不能保证网格已充分解析爆破的短波和损伤带；仍需做动态结果的网格与时间步收敛检查。

实际孔壁必须是闭合内边界，至少有 6 条网格边，节点到识别圆周的误差不超过孔半径的 3%（与原生核心一致）。“识别并填入炮孔”从当前实体网格拟合圆孔，单孔填入中心和实际孔半径，多孔要求用户选择。它保留独立的装药半径、网格与压力参数。运行时也会识别指定中心的实际孔壁，匹配不到中心或装药超出孔壁时会在提交求解前报错。检测尺寸受网格离散与坐标舍入影响。

## 不耦合装药与空气间隙

支持同心装药与孔壁之间保留空气间隙：`radius` 是实际孔半径（由网格读取），`chargeRadius` 是用户设置的装药半径，满足 `0 < chargeRadius <= radius`。径向间隙为 `radius - chargeRadius`，例如孔半径 1 m、装药半径 0.5 m 时保留 0.5 m 空气间隙。TNT 图标按装药半径绘制，浅蓝色环区表示空气间隙，压力加载于实际孔壁，装药不必贴壁。旧模型缺少 `chargeRadius` 时按已有半径恢复装药尺寸；运行仍会从当前网格读取实际孔壁。

`sourceMode=0`（直接给定压力）求解岩体对**给定孔壁压力时程**的响应，不离散空气域。因此，装药半径影响几何示意，给定相同孔壁压力时，空气间隙不自动引入压力衰减或传播延迟。界面明确标为“孔壁峰值压力”。`sourceMode=1` 已新增径向产物—空气动力学与平均孔壁反馈，可选择常规参数、JWL 或自定比热比，计算空气传播延迟和孔壁压力，详见 [气体耦合模型、输入及范围](GAS_COUPLING.md)。

新增 11 项回归覆盖独立装药尺寸、自动识别孔壁、给定压力下的响应一致性、围压、边界识别、多孔选择、自适应网格直接求解、共享网格复用、旧模型兼容与 TNT 间隙显示，总计 135 项。


“TNT 爆破可视化”把炮孔爆源示意叠加到爆破扰动应力场 `σ(t)−σ(0)` 上；普通应力视图显示总应力，包含初始围压。待起爆时显示装药图标，脉冲期间随孔壁压力高亮，结束后显示灰色图标。绘图、计算和其他爆破结果视图也显示爆源位置，可用“显示 TNT 爆源示意”关闭。结果侧栏的压力图和当前时刻指示线与时间帧同步。

TNT 视图使用全历程统一应力色标，避免各帧重新归一化造成波强度误读。青色线来自当前帧中超过全历程峰值 3% 的单元与其未超过阈值邻居之间的实际网格边，它是应力响应阈值边界，不是经过首波到时识别的精确物理波前。深色描边标记 d≥0.8 的计算单元，不凭空生成裂缝。以上图层只用于显示，不改变求解输入。TNT 外形仅为图标，压力仍使用给定脉冲，没有 TNT 装药质量到压力的换算，也没有新增爆轰状态方程。

自建模型时，坐标必须以 m 为单位；外部边界内绘制圆形炮孔，把孔内区域设为“外部空气”。材料库的 E 单位为 GPa、强度为 MPa，前端会按现有规则转换到 Pa；密度为 kg/m³。炮孔中心、半径必须匹配几何。至少需要 6 条孔壁网格边，推荐明显更多。

该功能复用当前有效普通或自适应网格，不启动静力 ZZ 迭代；独立于 OpenCL 开关，动力计算目前在 CPU 上完成，较大模型使用最多 8 个 OpenMP 工作线程。爆破帧不使用静力安全校核。

## 外载荷与初始平衡

默认先用当前模型的弹性刚度、约束和恒定外力求解 `K u₀=F₀`，再以 `u=u₀,v=0` 开始爆破，整个动力阶段保持 F₀。前端的节点载荷已经包含点力、分布力和体力，C++ 与原静力核心一样以节点载荷为准，不再次叠加用于导出核对的单元等效力记录。围压快捷输入对应外层边界的 `t=diag(−px,−py)n`，按边长积分后加到 F₀。只作用于最外层闭合边界，不给炮孔及其他内部孔洞加围压。

无实际位移约束且荷载自平衡时，每个连通实体单独添加静力坐标基准，去除三个刚体模态。这些基准不会带入动力约束，且求解后检查其反力：不能自平衡的净力/净力矩会明确报错，需要添加真实支承、平衡外载荷或选择突然加载。不会用隐藏支承维持非平衡地应力。

初始阶段为弹性平衡。若启用损伤且初始平衡已超过抗拉强度，程序拒绝继续；当前未实现预损伤非线性静力平衡。模拟已有严重开裂的初始岩体需要进一步扩展。选择“起爆时突然施加外载荷”时则从 u=0、v=0 开始，外力本身也会产生冲击波。

平面应变适用于二维截面的面外应变约束。输出保留 σzz，等效应力计入面外应力；DP/JH2 用完整三维应力张量计算材料不变量。小变形裂带模型仍以面内最大主应力驱动损伤；这些材料状态计算并不等于三维空间离散或碎块接触。

## 反射和吸收边界

全局条件应用于外层边界，逐条覆盖按几何边界编号 C1、C2 等配置；设置随模型 JSON 保存。覆盖只映射到真实暴露的网格边，内部材料界面不受影响，炮孔壁始终保留压力边界。

- 沿用原约束：保留模型已有固定/自由状态，都会反射出射波。
- 自由面：释放该边节点的固定约束，形成自由反射面。
- 固定边界：固定该边两向位移，形成固定反射面。
- 吸收：释放该边原固定约束，增加法向/切向黏性边界。交角处若同时有明确固定条件，以固定条件优先。

使用 `t_n=−ρ c_p v_n`、`t_s=−ρ c_s v_s` 的局部黏性吸收，依据相邻材料参数取 `c_p=sqrt(Dxx/ρ)` 和 `c_s=sqrt(G/ρ)`，与选定的平面假设一致。每条边以 L/2 的权重分配两端的 2×2 阻尼矩阵，保留斜边的法向/切向耦合。围压和其他恒定外力在吸收阶段继续保持，阻尼仅作用于动态速度。方法依据见 [Itasca 的 quiet boundary 说明](https://docs.itascacg.com/itasca920/flac3d/docproject/source/options/dynamic/considerations/considerations.html)。

这是近似吸收条件，不能保证斜入射、角点、强非均质介质和损伤区的所有波都零反射。它没有实现 PML、自由场耦合或精确无限域。边界应布置在远离炮孔、主要破坏区的位置，并进行边界距离和网格收敛检查。

- `mfem-4.10/examples/ex23.cpp`：二阶波动方程算子及受约束自由度的处理。
- `mfem-4.10/reference/newmark-step.cpp`：`linalg/ode.cpp` 的 `NewmarkSolver::Step` 原始片段。

`BlastDynamics.cpp` 把 Newmark 更新式改造成 β=0、γ=1/2 的显式中心差分，适配本程序的节点、TRI3 单元和管道通信。这里没有链接完整 MFEM，也没有把 MFEM 的超弹性示例宣称为爆破或断裂模型。质量集中、炮孔加载、损伤本构、历史输出和 UI 是本项目新增。

## 方程与时间步

采用 `M a +(α M+C_absorb)v+f_int(u,d)=F₀+f_pressure(t)`，厚度 1 m。TRI3 节点集中质量为 `ρ A / 3`；内力为 `A Bᵀ σ`。固定自由度的 u、v、a 保持为零。

给定压力模式的压力为 `p(t)=p_max sin(πt/Tp)`（0≤t<Tp），随后归零。仅在实际网格单侧边中选择匹配圆周的完整闭合孔壁；按边长积分到两个端点，方向由相邻实体三角形确定。不会用体内的虚拟圆圈替代孔壁。圆周匹配容差为半径的 3%。

令 `λ_bound=max_i Σ_j |K_ij|/M_ii`（实现按单元绝对行和累加，保守高估）。使用 `dt≤0.7×2/sqrt(λ_bound)`，给定压力时同时限制 `dt≤Tp/20`；气体模式改用初始声速及装药/间隙尺寸约束并在内部 CFL 子步推进。实际 dt 均分总时长，精确到达终止时间。用户指定过大的 dt 会被拒绝。α 为质量比例阻尼，单位 1/s。总阻尼通过每节点的 2×2 速度校正求解处理。

## 拉伸损伤

这是本项目的简化本构，不是 MFEM 自带断裂求解器。先按选定的平面弹性矩阵求总试应力，取最大正面内主应力作为损伤驱动，保留历史最大值 `κ=max_history(max(σ1_trial,0)/E)`。设 `ε0=ft/E`，特征宽度 `h=sqrt(2A)`，指数软化尺度为 `s=Gf/(h ft)−ε0/2`。

当 κ>ε0 时，`d=max(d_old, 1−(ε0/κ) exp(−(κ−ε0)/s))`。试应力的正主值乘以 `max(1−d,10⁻⁶)`，负主值保持不变，再旋转回全局坐标。关闭损伤时恢复线弹性。

该软化尺度使单轴、完全局部化且忽略残余刚度时，单元带的总拉伸应力应变积分对应 Gf。若 `Gf/h≤ft²/(2E)`，该形式不能容纳弹性储能，程序要求细化网格或检查材料参数。能量与单元尺寸关联的指数软化可参考 [INL/MOOSE 的 ExponentialEnergyBasedSoftening](https://mooseframework.inl.gov/falcon/source/materials/ExponentialEnergyBasedSoftening.html)；本实现并非其完整旋转裂纹本构。

运行前现在会自动处理网格与断裂能不匹配：计算每个单元的实际 `h=sqrt(2A)`，对不满足严格条件 `h<2E Gf/ft²` 的单元做红细分，并对相邻单元做绿细分以保持共形。材料界面共用边中点，孔洞、边界曲线编号和边界参数区间保留；不移动原节点，不翻边，不改变用户输入的强度、Gf 或损伤公式。细化成功后写回共享网格，重新分类并积分外载荷，后续结果和模型导出使用同一网格。再次运行会复查，兼容时直接复用。静力 ZZ 自适应与这项几何兼容检查是不同的条件。

细化在后台 Worker 中执行，支持“取消”；超过 60 秒、16 轮、预计 250000 节点 / 500000 单元或最小单元面积时会停止并给出原因，尚未提交的细化不会覆盖原网格。节点目标上限仅控制普通布点，损伤兼容细化可能超过该值。爆破接口单次请求上限为 256 MiB，以容纳细化后的模型；其他接口仍为原来的 50 MB。缺失单轴抗拉强度仍需要填写。


该组输入的完整 0.2 ms 验证输出 4995 步 / 101 帧，本机约 96 秒（包含细化、计算与逐帧检查）；全部单元应力与损伤有限、损伤不回退，最终 72345/139642 单元 d>0.01。气体能量相对误差约 8.6×10⁻¹⁵。另经 Worker → 网格写回 → 正常导出 → 原生核心的 0.02 ms 回归验证，实际 HTTP 模型 JSON 约 73 MB。批量节点分类复用当批的曲线采样及包围盒，避免细化后的大网格反复采样圆弧；下一批重新取样以响应几何修改。

多轴加载、旋转主应力、平面应变约束、非均匀三角形及残余刚度会改变耗能，不是严格的多轴能量一致性保证。U 是当前 `ΣA ε:σ/2` 的诊断量，U₀ 是爆破前弹性储能，W 仅累积动力阶段外力功，D 是质量阻尼及边界阻尼耗能。有损伤时不能把 `U₀+W−K−U−D` 全部解释为精确断裂耗能。

## 输出与验证

`POST /api/blast-runs` 接收 `{model,settings}`，返回帧摘要和按帧读取 URL。原静力协议不变；爆破输入复用 FEMBIN01，输出使用 FEMBLT02 流：尺寸与计算元数据、逐帧 8 个 Float64 标量（气体模式为 12 个，另加气体内能、动能、壁面功、半径）、u[2N]、v[2N]、单元[7E]。标量为时间、压力、K、U、W、D、总应力峰值、扰动应力峰值。单元数组为 `[εxx,εyy,γxy,σxx,σyy,τxy,d]`；前端转换 `εxy=γxy/2`。

已移除 200 万历史值和 2 亿单元更新的总量拒绝条件，也没有截去用户要求的保存帧。C++ 直接输出二进制帧，Node 顺序接收并逐帧 gzip 保存，不缓存整个 stdout 或构造完整 JSON。浏览器缓存初始帧及至多两个其他帧，快速拖动时取消过期请求。导出在服务端逐帧转成完整 JSON 并流式压缩下载，不在浏览器展开所有历史。

当前边界：最多 201 帧、单帧 256 MiB、单次压缩历史 4 GiB、2000 万时间步；超限明确报错。最长计算时间默认 600 秒，可配置 1–7200 秒，支持取消并终止原生子进程。同一服务器最多同时运行两个爆破任务。若实际步数少于帧数，返回步数加一帧以避免重复时刻。

压缩文件保存在系统临时目录的独立 `fem-blast-*` 文件夹。每服务器保留最近最多 8 个完成历史，在新计算时清理超过 12 小时的历史；正在下载的历史受保护。服务正常退出时删除本进程创建的临时历史；强制结束进程或断电时可能留下临时目录。服务重启或历史清理后需重新计算，因此需要长期保留时请下载压缩 JSON。没有完整历史重载 UI。程序接口 `runBlastCore` 默认兼容返回小模型完整数组；超过 128 MiB 的接口调用应使用 `{lazy:true}`。
