# 气体本构与爆破设置限制

## 界面行为

本构、平面假设、运动学、加载方式、气体 EOS 或端部条件冲突时，爆破设置立即弹出“本构与计算条件不兼容”，写出受影响材料、不能计算的原因和修改方法。页面顶部持续保留红色说明，运行按钮禁用；修正后自动解除。界面不自动替用户切换平面假设或运动学。逐材料覆盖和未保存的本构草稿也参与检查。只有适用范围说明而没有确定冲突时，显示黄色提示，不阻止计算。

主要拦截条件包括：

- Neo-Hookean / Mooney–Rivlin 必须使用有限变形、平面应变；有限变形本身也不能选平面应力。
- Maxwell、MCC 和正交各向异性目前只能用小变形。
- MCC 必须先静力平衡，有正有效围压或已有压缩外载荷；是否所有单元均在正压和屈服面内仍需初始求解确认。
- 超弹性 / HJC 暂无非线性静力预平衡。已知非零围压、外载荷或气体模式的初始背景压力与“先静力平衡”组合会被拦截，需改用突然加载或其他本构。
- 非理想气体参数未填完整、余容积越界、初始压力或声速平方非正、van der Waals 不在支持的单相区时不可运行。
- 新非理想气体暂不允许与原有轴向泄流公式组合，必须选择“两端封堵”。若气体模式未启用，气体选择不影响给定压力计算。

本构自身不包含的行为，如 JC 断裂、MCC 孔隙水、近不可压 TRI3 的体积锁死风险及各模型变体，仍在相应模型的说明中显示。土体的实际初始应力、材料屈服面、网格质量等需要求解才能确定的条件仍由原生核心校验，界面不会伪造“已通过”的结果。

## 新增气体 EOS

产物与间隙气体可以分别选择 EOS。原来的理想气体、JWL、等效 CJ 的 ID 和默认值保留；新模型接入压力、绝热声速、间隙初始能量反算、CFL、材料界面、重分区、孔壁功和历史输出。

| ID | 模型 | 建议使用范围 | 显式限制 |
|---|---|---|---|
| 0 | 理想气体（原有） | 常压、稀薄气体及基准验证 | 常 γ，不含分子排斥/吸引 |
| 1 | JWL（原有，仅产物） | 有标定参数的已反应爆轰产物 | 不是反应速率模型 |
| 2 | 等效 CJ（原有，仅产物） | 由密度、爆速、爆热构造理想产物近似 | 不能代替高密度炸药标定 JWL |
| 3 | Noble–Abel | 需要余容积修正的稠密气体或产物 | b>0，bρ<1，正热能 |
| 4 | Stiffened Gas / 刚性气体 | 有实验参数的压力偏移近似、声学阻抗验证 | p∞>0；不是高精度真实气体数据库 |
| 5 | NASG | 同时有排斥和压力偏移的可压缩介质近似 | b>0、p∞>0，bρ<1 |
| 6 | van der Waals | 高温单相气体的分子排斥和吸引定性研究 | a>0、b>0、T>Tc、稳定单相；没有相变求解 |

常压空气优先使用理想气体；高压气体可以比较经标定的 Noble–Abel。SG/NASG 应使用实验标定的介质参数，不能仅更换下拉框就认定材料更准确。van der Waals 在临界区的定量精度有限，本实现也没有气液相平衡，不应拿它代替完整真实流体数据库。

## 单位与方程

统一用正绝对压力 p、质量密度 ρ、比内能 e，SI 单位分别为 Pa、kg/m³、J/kg。γ 为常数。新增字段在 JSON / settings 中为：

| 字段后缀 | 物理量 | 存储单位 | 界面单位 |
|---|---|---|---|
| Covolume | 余容积 b | m³/kg | m³/kg |
| PressureOffset | 压力偏移 p∞ | Pa | MPa |
| EnergyShift | 参考比能 q | J/kg | MJ/kg |
| Attraction | 吸引系数 a | Pa·m⁶/kg² | 同左 |

产物使用前缀 `product`，如 `productCovolume`；间隙气体使用 `air`，如 `airEOS`、`airCovolume`。新增字段默认 0，旧项目和参数库读取后补齐默认值。选定新模型所要求的正参数不能用 0 代替。未启用字段保留编辑值，但不进入所选 EOS 的计算。

本实现沿用原求解器的正比内能约定，限制 q≥0、e>0；不支持任意负能量零点。p∞、b、a 也取非负值。基本 γ 范围为 1<γ≤10，原理想间隙气体仍为 1<γ≤2。

令 `d=1−bρ`。Noble–Abel、SG 与 NASG 使用同一热力学闭合：

```text
p  = (γ−1) ρ (e−q)/d − γ p∞
c² = γ (p+p∞)/(ρ d)
e(ρ,p) = q + (p+γ p∞) d/[(γ−1)ρ]
```

Noble–Abel 取 p∞=0；SG 取 b=0；NASG 两者非零。初始间隙能量由所选 EOS 的 `e(ρ,p)` 反算，不能继续使用理想气体能量公式。所有计算状态必须保持 d>0、e−q>0、p>0、c²>0。

van der Waals 采用常定容比热闭合 `e−q=Cv T−aρ`：

```text
thermal = e−q+aρ = Cv T
p  = (γ−1) ρ thermal/d − aρ²
c² = γ (p+aρ²)/(ρ d) − 2aρ
e(ρ,p) = q + (p+aρ²)d/[(γ−1)ρ] − aρ
```

除正 p、正 c²、d>0 外，还要求等温导数 `(γ−1) thermal/d²−2aρ>0`，以及高于临界温度：`thermal > 8a/[27(γ−1)b]`。这里用 Cv 倍的温度比较，Cv 在临界判据中约去，因此不需要另给一个随意的绝对温度常数。本模块没有绝对温度输出、化学解离或温度相关比热。原始 GitHub cubic EOS 用摩尔量，改装后 b、a 为**质量比量**，不能直接填入摩尔参数。

声速平方在测试中同时与独立解析式和 `dp/dρ|s = ∂p/∂ρ|e + p/ρ² ∂p/∂e|ρ` 的有限差分比较，避免只增加压力公式而错误沿用理想气体声速。

## 求解范围与数值处理

沿用现有径向材料随动 HLLC/Godunov 和守恒重分区，两个材料不通过直接平均 EOS 系数混合。新 EOS 接入全部气体状态路径，包括反射孔壁、界面、重分区和 CFL。闭合端部时，内能、动能和孔壁功按相同总能量账本守恒。

一般状态使用通用声速 HLLC 波速估计；强膨胀导致其负星区压力时，沿用局部多方指数的正压接触返回。这个返回对理想气体有解析依据，**对非理想气体只是近似，不是每种真实气体 EOS 的精确 Riemann 解**；诊断中记录其次数。需要做气体网格、固体网格与时间步收敛检查。

新模型不通过压力下限或声速下限掩盖非法状态。积分子步会重试缩小 dt；仍然进入余容积奇点、非正压力、非双曲区或不支持的 van der Waals 区域时停止。没有相平衡、气液转换、黏性、湍流、导热、有限速率爆轰、再燃或扩散模型。既有轴向泄流是理想多方罐体近似，尚未推广到新 EOS，所以界面、设置校验和原生核心均拒绝该组合。

## GitHub 下载与改装

原始文件实际下载到 `third_party/real-gas-reference/`，保留不可变提交 URL、SHA-256 和原始许可：

- [LANL/singularity-eos](https://github.com/lanl/singularity-eos/tree/b4f71a7748770dfa6ce4d678754c463c09262fb7)：`eos_noble_abel.hpp`，BSD-3-Clause。将其压力、比能与体积模量关系改为本项目 SI 材料点接口；没有引入其 portability/Kokkos 框架，也没有保留上游的正值截断策略。
- [JorisCaze/NASG-EOS_Calibration](https://github.com/JorisCaze/NASG-EOS_Calibration/tree/7c5cbd8cedf79cf5cd7384927bf3053ab40022a5)：`calib_liq-vap.cpp`，MIT。参考其比体积、焓和压力偏移参数约定，形成与 NA 共用的 NASG 内能闭合。没有引入其气液饱和曲线或标定 Newton 求解流程。方程另核对 [NASG 热力学说明](https://www.basilisk.fr/src/compressible/NASG.h)。
- [shohirose/eos](https://github.com/shohirose/eos/tree/e1ab5dfeba75dda95c2a21c63d13447192fb191a)：`van_der_waals_eos.hpp`，MIT。将摩尔状态关系转为质量比量，补入常 Cv 内能、绝热声速和单相域限制；不链接其整套 cubic EOS 框架。

实际运行使用 `计算力学程序计算核心/GasConstitutive.h` 的改装核，与已有 `GasDynamics.cpp` 连接。新核心元数据带 `gasConstitutiveVersion:1`；选用新模型时旧核心会明确报版本错误，不会退回理想气体。
