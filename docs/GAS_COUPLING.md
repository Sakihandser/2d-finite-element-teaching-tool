# 材料参数驱动的气体—岩体耦合

在“爆破设置”的“压力来源”选择“材料参数 → 气体动力学计算孔壁压力”，即可用产物和间隙气体的材料参数求解孔壁压力，不需要填写峰值压力或脉冲时长。原给定压力模式仍可选择。点击“载入气体耦合验证示例（替换模型）”可复现界面验证；先保存需要保留的模型。示例全部是教学参数，未标定为 TNT。

## 用户可选模型

| 产物模型 | 必填材料参数 | 含义 |
| --- | --- | --- |
| 常规参数 | 初始装药密度 ρ₀、爆速 D、爆热 Q | 强 CJ、定比热理想产物近似；取 γ = √(1 + D²/(2Q))，初始比内能 e₀ = Q |
| JWL | ρ₀、e₀、A、B、R₁、R₂、ω | 使用用户标定的产物状态方程；A/B 不能同时为零 |
| 自定比热比 | ρ₀、e₀、γ | p = (γ−1)ρe，用于简化计算与数值验证 |

界面密度为 kg/m³、爆速为 m/s、比能为 MJ/kg、JWL A/B 为 GPa；内部统一转 SI。气体使用初始密度、绝对压力（界面 MPa）及比热比的理想气体 EOS。压力和密度共同确定初始比内能；当前不需要另填温度。气体并不限于空气，但必须适合定比热理想气体近似。

常规参数关系来自 [Caltech SDToolbox 手册](https://shepherd.caltech.edu/EDL/PublicResources/sdt/doc/ShockDetonation/ShockDetonation.pdf) 附录 A.7、式 A.78 的强爆轰极限。它把 D、Q 拟合成等效 γ，并非凝聚态炸药的通用 EOS，不会传播一个速度为 D 的化学反应前沿。实际高密度产物优先使用实验标定的 JWL；只有 D、Q 并不能唯一重建真实爆轰物理。程序接受 1 < γ ≤ 10，超出范围明确拒绝。

JWL 采用 LANL Singularity-EOS 的能量约定。令 x=ρ₀/ρ、a=A exp(−R₁x)、b=B exp(−R₂x)，则

```
e_ref = a/(ρ₀R₁) + b/(ρ₀R₂)
p = a + b + ωρ(e − e_ref)
ρ c² = (1+ω)ωρ(e − e_ref) + x(R₁a + R₂b)
```

ρ₀ 是参考装药密度，e₀ 必须与所用系数的能量基准一致，不能把其他能量约定的数值直接照搬。所有系数须来自同一套标定数据。EOS 离开正压、正声速平方的物理域时停止并报错。

## 数值实现及来源

已下载 [Clawpack Riemann](https://github.com/clawpack/riemann) 和 [CEED/Laghos](https://github.com/CEED/Laghos) 到 main 与 ML 分支之外。选定源文件、原始版权、完整许可与固定提交哈希收录在 `third_party`，详情见 `third_party/SOURCES.json`。运行不需要安装 Python、Clawpack、MFEM 或其他外部求解器。

当前 `GasDynamics.cpp` 改造 Clawpack 的 HLLC 接触速度与星态压力公式，采用一般 EOS 声速估计、随材料运动的有限体积和守恒总能量更新。JWL 压力、参考能量和体积模量改造自 [LANL Singularity-EOS](https://github.com/lanl/singularity-eos) 的 `eos_jwl.hpp`。Laghos 保留为调研参考，没有把其高阶求解器直接移植或链接进当前程序。

气体为单位深度的同心圆柱径向模型（r=0 对称，外壁随岩体运动），采用拉格朗日推进与按需守恒网格重整，产物与空气界面恰在网格面上，不做材料混合。当前是一阶 Godunov 空间/时间离散；柱坐标动量源保持等压静止解。气体 CFL 子步为 0.25h/(c+|u|)，正体积、正内能失败时缩小时间步重试，不能恢复时明确报错，不裁切负压。径向单元 16–2048，默认 192；整体计算受界面设置的运行时间限制，不再用固定的两百万累计气体子步拒绝加密或长时计算。

冲击后的空气可能压成薄环。某材料内最小单元宽度小于该材料平均宽度的 20% 时，重整该材料网格；材料占据的径向厚度显著变化时，按当前厚度重新分配单元，每种材料至少保留四个单元，采用两倍变化阈值减少频繁重映射。总单元数保持用户设置值，材料界面、原点和孔壁位置保持不变。在真实圆柱体积的重叠区域上积分质量、径向动量及总能量，分别守恒每种材料质量，将速度平均损失的动能计入内能；单个编号单元的质量可以改变。重整后仍检查 EOS 的正压和双曲性。重映射引入一阶数值扩散，孔壁尖峰仍须做空间、时间收敛检查；四单元下限并不保证薄空气层内所有波动均已解析。

岩体仍使用原有二维 TRI3 小变形动力学、外载荷、围压、边界条件及连续拉伸损伤。已有有效均匀/静力自适应网格均可复用。独立的径向气体网格在程序内部生成，不需要给孔内空气划 TRI3 岩体网格。

## 孔壁反馈与输出

孔半径 R 从真实网格识别，装药半径 r_c 可小于或等于 R。气体初始为已反应的产物，空气占据 r_c 到 R；没有空气间隙时直接由产物加载孔壁。气体模式先把初始环境气压加入岩体外载荷，再按选定方式做静力预平衡。动力阶段施加相对环境的气体增压，避免重复施加环境压力。

孔壁二维节点的法向位移通过原压力载荷向量 F_p 的功共轭量确定平均体积变化：V = πR² + F_p·(u−u_preload)，随后换算等效半径传回气体。每个岩体时间步使用气体的平均压力作动力载荷；帧中保存瞬时反射孔壁绝对压力。间隙会产生传播延迟和反射；计算结果随气体、岩体网格和时间步变化，需做收敛检查。

气体帧使用 `FEMBLT02` 的 `frameScalarCount=12`：保留原八标量，再追加气体内能、动能、对壁做功、等效孔半径。旧给定压力仍是八标量。帧压缩、按需加载、完整 JSON gzip 导出沿用既有流式机制；元数据包含 sourceMode、productEOS、effectiveProductGamma、initialGasEnergy。JWL 的 effectiveProductGamma 仅代表 1+ω，不能解释为恒定实际比热比。

结果页曲线绘制实际保存的孔壁压力；诊断显示气体 U、K、Wwall 和 (U+K+Wwall−E₀)/E₀。气体守恒误差不等于整个流固系统的离散误差，也不能证明材料模型已标定。

## 验证及范围

原生验证覆盖 Sod 激波管与独立精确解的网格收敛、静止多材料接触、运动圆柱壁的能量账目、JWL 声速与等熵导数、空气间隙到壁延迟、孔壁功匹配、常规参数与等效 γ 的一致性、给定脉冲参数不影响气体模式，以及旧帧协议兼容。新增 5 ms 压缩空气长时算例，检查网格加密时压力冲量收敛、分材料质量、总能量、运动壁及 JWL 重映射，并验证 0.1 μs 步长的完整耦合计算。性能复现与较大模型结果见 [长时爆破优化验证](BLAST_PERFORMANCE.md)。此前浏览器验证的 952 节点 / 1752 单元模型见 [气体耦合结果](gas-coupling-result.jpg)、[模型设置](gas-model-settings.jpg)。

这仍是径向已反应产物的流固近似：不计算有限速率化学反应、氧化/再燃、起爆传播、偏心装药、沿孔轴流动、裂缝泄气、角向非均匀气流或实际碎块分离。气体只接收平均孔壁变形；损伤出现后仍按封闭孔腔计算，不能把损伤带当成已打开的泄气通道。强稀疏波进入真空或严重孔腔塌缩会明确失败。尖峰压力对网格敏感，保存帧数也可能漏掉尖峰；数值验证不替代实验标定。
