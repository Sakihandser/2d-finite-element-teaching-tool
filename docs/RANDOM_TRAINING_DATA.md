# 随机训练模型生成器

在 **machine-learning 分支 → 神经网络训练 → 自动生成训练数据** 使用。
启动后可直接点击“预览随机模型”或“开始批量生成”，无需手工创建几何。
程序不会在每次启动时自动运行耗时批次；运行中的批次在切换页面后继续计算。

## 使用方法

1. 设置随机种子、基础几何数量、每个几何的物理工况数。打开页面时，种子默认为运行电脑的本地时间 `YYYYMMDDHHmmss`，共 14 位；点击种子旁的“刷新”更新为当前时间，仍可手动填写种子以复现批次。同一秒刷新可能得到相同种子。
2. 选择矩形、三角形、圆、椭圆、随机凸多边形，设置最多图形、区域和孔洞。
3. 选择点力、线性分布载荷、体力和载荷组合方式。默认“均衡抽样”在已选类型的非空组合之间轮换；“全部所选类型”在每个工况同时施加全部类型。在主面板设置每个工况的最多加密轮数、每轮耗时、总耗时和参考节点上限。展开高级选项设置尺寸、载荷幅值、材料与基础网格预算。
4. “预览随机模型”显示第一张几何的第一个工况。绿色为固定支撑、红色为外载荷、紫色为体力。
   “载入预览到结构绘制页”会用预览替换当前绘图模型，可继续编辑和求解。
5. “开始批量生成”在独立进程中建立参考网格并调用现有 C++ 求解器，按 ZZ 估计误差局部加密。
6. 自动导入仅接受实际 ZZ 误差不高于目标的有效参考工况，每个工况重新从纯几何建立三种输入粗网格。
   “自动加入用途”可选择全部加入训练集、全部加入验证集，或按验证几何比例自动划分。指定用途时忽略验证比例。
   取消“计算后自动加入训练数据”则只生成参考文件；之后可在历史表格选择训练集或验证集，点击“分配”。
7. “完成当前工况后暂停”等待正在运行的工况完成（含其导入）并保存进度；看到“已暂停”后可关闭程序。
   在“生成记录”选择批次，点击“继续所选批次”可生成剩余工况，重启程序后也可继续。
   继续时沿用该批次的随机种子、参数、材料快照和用途划分，当前面板修改不影响续生成。
   已完成或已失败的工况不会重跑；中断时已写完的参考模型会复用，尚未写完的当前工况会重新计算。
   生成任务和训练/预测/模型修改互斥；先保存并暂停训练才能开始生成。
8. 从表格下载参考 JSON 或预览，下载批次记录查看参数、失败原因和样本 ID。
   历史批次在重启后仍可访问。异常关闭时显示“已中断”，点击“继续所选批次”手动恢复；
   旧版记录中已停止、失败的批次有剩余工况时也支持继续。

批次记录与源模型采用独立临时文件和原子替换保存。Windows / OneDrive 临时占用导致的
`EPERM`、`EACCES`、`EBUSY` 会退避重试，最多 8 秒，不先删除上一份完整记录。
单工况的几何、网格、求解或文件生成失败会记录原因并继续后续工况；导入失败保留参考文件供手动分配。
如果批次记录仍无法保存（如持续锁定、磁盘已满），任务安全暂停，避免继续生成无法登记的数据；
恢复文件访问后可点击“继续所选批次”。当前程序保留最新内存进度，重启后以最后成功落盘记录恢复。

## 历史记录管理

- 每个历史工况的“预览”旁提供“删除”，直接删除该工况的源模型、参考模型和求解结果等文件，并更新批次记录。删完最后一个工况时移除整个批次目录。
- “删除当前批次”移除选中批次的全部文件；“删除所有历史生成数据”覆盖全部批次，包括未完成批次遗留文件。
- “删除已分配历史生成数据”只清理当前仍在训练库中有对应副本的历史工况，保留同批次内未分配的工况。全部工况都符合时移除整个批次。
- 删除前列出批次、工况、文件数量和磁盘大小。确认时重新核对文件及分配状态，清单发生变化需要重新确认；运行训练、生成或其他历史管理操作时禁止删除。
- 以上操作仅清理 `storage/generated/` 下的生成批次文件，**保留** `storage/datasets/` 中的独立训练/验证副本和模型检查点。要删除训练库副本，请在“选择训练数据”中操作。
- “已分配”以训练库中实际存在的记录为准。训练副本被删除后，只要参考历史文件仍存在，即可重新分配。未生成有效参考文件的失败工况不能分配。
- 手动分配复用现有导入器，建立三种输入粗网格并验证参考数据；同一几何的多个工况必须位于同一用途。仅因未达目标精度而被自动过滤的有效参考也允许手动分配，保留其实际误差。

## 几何和物理逻辑

- 第一张基础图形随机选择类型、尺寸和方向，后续图形在当前外轮廓处重叠拼装。
  仅接受具有足够重叠面积、增加有效面积、且合并后为单个连通面域的结果。
- 随机方向的直线切割形成几何材料区域，拒绝过小、过窄的区域。切割发生在网格生成前，
  材料界面参与 PSLG 约束网格，避免仅在网格节点上贴不连续材料标签。
- 孔洞完全位于单个区域内，与外轮廓、材料界面和其他孔洞保持间距，并作为空气区域导入。
- 圆和椭圆当前采用 **24 段多边形近似**；生成结果中的边界类型是直线。
  点坐标按 1e-6 m 几何精度处理，与程序区域识别的节点精度一致。
- 对全部边界作交点打断，复用共享曲线和端点。导入后再次核对区域数、孔洞数和材料是否保留。
- 在有效的非零长外边界中随机选择一条完整固定边，固定两个位移分量，消除二维刚体运动。
  固定边不取孔壁或内部材料界面；点力避开固定端点，线载荷取另一条外边界。
- “全部所选类型”中每种启用类型都会出现；“均衡抽样”按几何/工况序号覆盖非空载荷组合，小批次不保证覆盖全部组合。均衡模式优先较长的有效支撑边、点力避开紧邻固定端的顶点并使用不重复的作用点。历史批次缺少此设置时继续使用原来的全部类型采样随机流。
  点力数量 1–3；点力幅值 N、线载荷强度 N/m
  在输入范围内按对数均匀分布采样；线载荷终值为初值的 0.1–1.8 倍。
  体力随机作用于整体或某个结构区域，加速度在 1–20 m/s² 均匀采样；密度来自材料。
- 当前材料来自程序材料库，要求正的弹性模量、正的密度及 -1 < ν < 0.49。
  E 的场景单位为 GPa，交给求解器时按原有逻辑转为 Pa。
  批次开始时保存材料库快照，运行期间的材料库编辑不会改变该批次参数。
- 高级选项提供“连续直线外边界”：支撑沿相邻、共线的外边界段延伸，跨材料切割造成的分段时保持连续，不绕过几何拐角。默认仍为单条外边界。
- 高级选项的“点载荷形式”默认“理想集中力”。选择“有限宽度边界载荷”时，在自由直线边中部建立新的对称均布加载工况，宽度为该边长度的指定比例（默认 0.2，范围 0.02–0.8），强度为采样合力除以实际宽度。
  其合力和相对于所记录中心的合矩与中心集中力一致；作用位置是该自由边中部，不能当成原顶点集中力工况的同一份标签。
  场景使用实际分布载荷求解、预览和训练，`dataGeneration.finiteWidthLoads` 保存实际米制宽度、加载中心和合力。集中力类型与其他载荷类型同时启用时，有限宽度载荷和普通线性载荷使用独立编号。
- 几何、每个工况、数据用途使用独立的确定性随机序列。
  同一种子、几何参数和相同运行环境可复现几何和物理条件；求解耗时保护会受机器负载影响。
  生成记录保留实际拼装图形、实际区域数及孔洞数；最多数量是上限，几何质量约束可能减少数量。

## 标签质量和数据划分

本项目神经网络预测的是 **局部网格尺寸场**，并不是上游的位移图像扩散模型。
因此生成链路为：

```text
随机 CAD 和物理条件
  → Triangle 约束基础网格
  → C++ 线弹性平面应力 TRI3 求解
  → 现有 ZZ 误差估计、标记及 Triangle 局部加密
  → 已求解的最终参考网格 + 实际误差 + 停止原因
  → 现有训练导入器
  → 从纯几何重新生成 400 / 1000 / 2000 节点预算的粗网格
  → 图网络尺寸标签
```

节点预算、加密轮数和耗时上限均不是精度达标。界面显示 **实际 ZZ 估计误差**。
自动导入必须满足 **0 < 实际 ZZ 误差 ≤ 请求目标**，不能仅凭停止原因判断达标，也不能通过旧客户端的 `targetOnly:false` 绕过此检查。
未达标工况显示“未达到目标，未导入”，文件仍保留，可检查后手动分配。
实际误差不在 (0,1) 内、无有效自由节点载荷、支撑不足、材料/拓扑错误或求解失败的工况会被拒绝。
训练器的参考尺寸投影若使用最近质心回退，次数保留在训练样本的 `projectionFallbacks` 和批次工况记录中，
需要高质量标签时可在批次记录和训练样本元数据中检查该值。
后一轮求解超时、候选加密超过节点预算时，保留最后一次成功求解的参考网格，避免错配旧误差和新网格。

选择按比例自动划分时，验证用途以 `SHA256([seed, "split", geometryIndex])` 的前 32 位与验证比例比较。
同一几何的工况不会跨训练/验证集，比例是期望值，小批次不保证具有验证集。
既有训练器还会再次检查几何分组，拒绝同一几何跨用途导入。
调整验证比例或重复生成时，若与已有工况用途冲突，显示导入失败，参考文件仍保留。
重复工况若已存在于另一用途，也会明确提示冲突，不会默认为新用途导入成功。

主面板默认最多加密 **16 轮**、每轮 **30 秒**、工况参考计算总计 **600 秒**。加密轮数范围 0–100，不含首次基础网格求解；每轮耗时范围 1–3600 秒，总耗时范围 1–86400 秒。
参考节点上限默认为 **30000**，约束自适应加密后整张参考网格的总计算节点数，包含已有节点和新加密节点。加密前按共享边中点预算缩小标记集合；若 Triangle 质量节点使实际候选仍超预算，最多尝试 4 次、逐次缩减标记数量。全部尝试共用本轮剩余时间。仍无法满足时保留上一张已成功求解的网格。上限不是每轮新增节点数，也不是基础网格节点数。基础节点预算是独立参数，默认仍为 400。

### 有界热点补救与奇点保护

- 训练生成使用独立的 `bounded-raw-error-with-compact-point-protection-v1` 标记策略，普通计算页仍使用原标记策略。
- 优先按原始 ZZ 指标分配有限标记预算，每轮最多标记 1600 个单元，并给点力补点和粗背景保留有限份额。全域 ZZ 误差定义和自动导入的精度门槛不变。
- 普通尺寸下限冻结超过 25% 的误差指标能量时，可逐级放宽下限，最多 3 级。绝对面积下限为 1e-10 m²；点力核心区保持原尺寸下限，不随补救级别降低。
- 点力保护在局部半径内平滑衰减并终止，不再把保护范围无限延伸到远处固定端。连续 3 轮相对误差改善不足 0.5% 时停止；主要误差被点力保护冻结则标为 `singularity-limit`，否则为 `stagnation`。未达目标的工况仍不会自动导入。
- 每次候选加密运行在独立线程中，设有 768 MiB 的 JavaScript 老生代堆限制以及包含初始化/通信的耗时保护。该堆限制不等于整个进程或 WASM 内存的严格总上限；节点预预算、候选节点检查和进程总时限共同限制开销。超时会等待线程终止后再返回，重试不会叠加后台加密线程。
- Triangle 还使用 `S<剩余节点>` 限制质量优化主动加入的 Steiner 点，避免只在计算结束后才发现质量节点过多。该开关对强制交点存在例外，因此仍保留实际候选节点检查和线程保护；不会取消已有边界与材料界面约束。
- 加密超时、线程错误、退化网格或预算不足时保留上一份已解参考。网格与对应应力、位移和误差成套保留，不导出未解候选。
- 每轮历史记录补救级别、冻结/点力冻结/已标记误差占比、标记单元数、实际候选节点数和重试次数。界面展示末次加密的摘要。
- 反向边界按实际端点参数拆分，避免加密后线性分布载荷丢失。合力、合矩保留有独立回归检查。

历史表格分别显示已求解数、精度达标数、实际已分配数。手动分配未达标参考不会增加达标数。
只有该批次所有已完成尝试的耗时都已知时才显示每参考计算小时达标数；耗时不含训练图导入和批次几何采样，旧批次不虚构该指标。
总耗时从参考模型归一化和基础网格建立前开始计时，不包含批次几何采样与训练图导入。每次原生求解的超时取单轮限制与工况剩余时间的较小值。
达到总耗时时保留最后一次成功求解的参考，标记 `case-time-limit`；首次求解未完成则记为失败。同步网格操作在返回时检查预算，另有独立进程保护防止长期卡死，因此总限制不是实时系统意义的精确秒表。
批次开始时保存设置，生成期间锁定参数；修改后的设置用于下一批。

生成器不自动开始神经网络训练，也不修改已有训练检查点。
默认 5% 目标可能需要更多自适应轮次和更高节点预算；点力和固定边端点具有应力奇异性，
本功能不能保证任意随机模型达到所请求误差，ZZ 本身也不是严格误差认证。

## 本地数据与接口

```text
python_machine_learning/storage/generated/<批次ID>/
  manifest.json              参数、材料快照、进度、工况用途和失败原因
  g1-c1.source.json          原始随机几何和物理条件
  g1-c1.json                 可导入程序的参考场景、位移、ZZ 历史和生成来源
  g1-c1.result.json          对应 C++ 位移、应力、应变等完整结果
```

以上文件通过“历史记录管理”单独管理；删除会直接移除磁盘文件，操作前请自行备份需要保留的数据。
自动登记的训练图位于原有 `storage/datasets/<样本ID>/`。
来源同时保存在场景 `dataGeneration`、训练 `metadata.json` 和 `reference.json` 中，
不作为神经网络输入特征。

本机同源 HTTP 接口：

- `GET /api/training/generator/status`：当前任务、全部历史批次摘要和实际分配统计。
- `POST /api/training/generator/preview`：生成并归一化第一张模型，不求解、不写入训练库。
- `POST /api/training/generator/start`：校验参数后启动后台批次。
- `POST /api/training/generator/stop`：当前工况完成后停止。
- `POST /api/training/generator/pause`：当前工况完成并保存后暂停。
- `POST /api/training/generator/resume`：提交 `jobId`，按原参数继续选定批次的剩余工况。
- `POST /api/training/generator/assign`：`jobId`、`key` 和 `split`（`train` / `validation`）指定历史参考工况及用途。
- `POST /api/training/generator/delete-impact`：`scope`（`all` / `assigned` / `job` / `case`）及对应 `jobId`、`key`，返回文件清单统计与确认令牌。
- `POST /api/training/generator/delete-history`：提交相同范围及确认 `token`，重新核对后物理删除，返回成功与失败列表。
- `GET /api/training/generator/manifest/<批次ID>`：下载批次记录。
- `GET /api/training/generator/sample/<批次ID>/g1-c1`：下载参考场景。
  `?preview=1` 为内联读取，`?source=1` 读取生成前的模型。

每个参考工况运行于独立 Node 进程，单次求解超时沿用现有 C++ 进程保护；
另有进程总时限 `60 + min(caseTimeLimitSeconds, (maxIterations+1) × timeLimitSeconds × 3)` 秒，给进程初始化和文件写入留出余量，防止同步 WASM 长时间占用。
失败记录后继续下一个工况，无无限重试。每批最多 200 张几何 / 1000 个工况。
当前跨程序实例的批次调度锁尚未实现，建议同一项目只启动一个服务实例。

## 依赖和源码

在现有 Python CUDA 虚拟环境中安装：

```powershell
.\python_machine_learning\.venv\Scripts\python.exe -m pip install -r python_machine_learning/requirements-generator.txt
```

当前固定 `shapely==2.2.0`，沿用现有 NumPy。无需安装 Gmsh、SfePy、PyVista 或 scikit-learn。

- `python_machine_learning/random_geometry.py`：独立实现的 CAD 布尔运算、区域切割、孔洞和物理采样。
- `python_machine_learning/generation-core.cjs`：参数校验、几何适配、现有网格/求解/ZZ 复用。
- `python_machine_learning/generation-worker.cjs`：独立工况进程。
- `python_machine_learning/generation-refinement.cjs` / `generation-refinement-worker.cjs`：节点预算缩减、有限重试、可终止的加密线程。
- `scripts/benchmark-generation-yield.cjs`：读取已有工况并运行独立种子验证，只输出指标，不修改历史或导入训练库。
