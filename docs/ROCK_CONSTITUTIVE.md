# 岩石本构接口

爆破设置支持默认本构和逐材料覆盖。参数由用户输入，保存在材料库、模型快照和求解输入中；程序不内置特定试件或材料标定参数。

| 本构 | 使用范围 | 主要输入 |
| --- | --- | --- |
| 线弹性 | 弹性波传播和加载检查 | E、ν、ρ |
| 拉伸损伤（裂带） | 张拉软化 | E、ν、ρ、实测单轴抗拉强度 ft、断裂能 Gf |
| Drucker–Prager + 拉伸损伤 | 压力相关剪切屈服与张拉软化 | 上述参数、单轴抗压强度 fc、摩擦角和剪胀角 |
| JH2 | 高应变率、压力相关脆性破坏 | 独立的 JH2 参数卡、剪切模量和密度 |

各本构的损伤变量定义不同。JH2 的静水拉伸强度 T 与单轴抗拉强度 ft 是独立物理量。

## 参数与积分

内部求解采用 SI 单位，界面显示的 GPa、MPa、mm 和 ms 按字段单位转换。DP 使用压缩为正的压力 p=-tr(σ)/3、q=√(3J2)，采用独立剪胀角的返回映射。

JH2 使用完整强度、破碎强度、应变率和累积塑性损伤。归一化等效应力 σHEL 可直接填写；填写 0 时，按纵向 HEL 换算 σHEL=1.5(HEL-pHEL)。两种输入含义不能混用。多项式 EOS 的初始体积刚度由 K1 决定，剪切刚度由输入 E/ν 决定；压缩切线必须为正。

β 为膨胀能量比例。损伤参考长度为 0 时不作长度修正；正值启用 lref/h 的破坏应变缩放。这些参数需要独立标定，不应以云图颜色代替标定。

平面应变保留 σzz，平面应力通过完整材料状态的副本迭代施加 σzz=0。完整应力状态用于等效应力计算。参数检查及输入协议与普通静力求解兼容。

实现依据公开方程独立编写，参考 [Altair LAW79 / JOHN_HOLM](https://help.altair.com/hwsolvers/rad/topics/solvers/rad/mat_law79_john_holm_starter_r.htm) 与 [JH-2 constitutive model of sandstone for dynamic problems](https://pmc.ncbi.nlm.nih.gov/articles/PMC10858055/)。

## 运动学与气体

有限变形目前支持平面应变，更新当前单元面积、形函数梯度、材料旋转和孔壁容积。时间步根据当前几何和材料声速调整；帧时间为准确物理时刻。倒置或稳定步长塌缩会明确停止，当前不含动态重网格或碎块接触。

气体储气方式可选择仅炮孔容积，或连通张开损伤区的均压储气近似。后者施加相应压力反馈并单独记录储气功，不解析裂隙内的流动阻力和传播。

轴向端部支持封堵、单端或双端敞开，并可指定有效孔长和开启时间。开口采用带背压的可压缩储罐泄流，记录流出质量、焓和动能；JWL 使用局部等熵指数近似。它不包含沿孔轴的完整传播、封堵材料运动或外界气体倒灌。薄空气层可能显著限制显式时间步。

气体能量账目包括剩余内能、动能、孔壁功和流出能量。岩石可恢复能与塑性功为独立诊断量，气体守恒不等于完整多轴断裂能已经验证。
