# 自动恢复训练

## 本次问题

检查两条实际记录：原训练第 1 轮最佳验证损失约 0.16997，最后训练损失约 0.04、验证损失约 0.27；从最佳点恢复的新记录最终验证损失约 0.25。原控制器确实降低过学习率，但没有撤回已经偏离最佳点的权重。

原“恢复检查点权重”会重建优化器，以配置中的 0.001 起步，并清空最佳验证指针；下一轮即使比恢复时更差，也可能成为新记录的“最佳”。这不是原最佳点失效，而是训练方向和控制方式重复了原来的过程。降低学习率本身不会恢复模型权重，参见 [PyTorch ReduceLROnPlateau](https://docs.pytorch.org/docs/stable/generated/torch.optim.lr_scheduler.ReduceLROnPlateau.html)。

## 新流程

保留“自适应训练策略”作为总开关，默认开启自动恢复：

1. 恢复权重、更新数据或调整策略后，在下一次优化前验证当前权重并建立基线。普通暂停续训不额外插入基线评估，以保持原来的训练轨迹。
2. 验证误差比本阶段最佳值高 10%，同时出现明显训练/验证差距、训练损失较最佳点继续下降，连续 3 轮才判定需要处理过拟合。单轮噪声和单纯训练/验证差距不足以触发恢复。
3. 过拟合或达到平台期等待轮数时，恢复本阶段最佳权重，将**当前实际学习率**减半，重建 AdamW 以清除不适合当前尝试的动量。与调度器同轮触发时仅减半一次，避免重复衰减。
4. 对过拟合，权重衰减每次乘 5（至少 0.0005，最多 0.01），隐藏特征 Dropout 每次增加 0.05（最多 0.20）。平台期重试保持正则化设置。
5. 默认最多恢复 3 次；每次重新等待观察。恢复预算耗尽后再次持续停滞/过拟合，或达到早停耐心、学习率下限或总轮数上限时结束；结束后自动加载并保存最佳模型。早停设为 0 时，不因恢复预算耗尽而提前终止，仍按总轮数上限结束。
6. 人工暂停保持当前权重、优化器和数据位置；恢复次数、正则化、随机状态均随检查点保存。自动恢复只改变模型和优化器，不倒退总轮数、步数或已学习几何记录。

无独立验证集，或验证几何曾参与训练时，不使用该验证集回退、选择模型或早停；仍可按训练指标降低学习率。更换数据后会建立新阶段的验证基线。仅切换策略或改变学习率会保留同一数据划分下已有的最佳检查点。

界面显示自动恢复次数、实际学习率、权重衰减及 Dropout。学习曲线在恢复后的新阶段断开；历史损失保留。训练结束显示当前权重已恢复到最佳模型，最终指标来自重新评估后的最佳权重，而最后一条曲线仍表示实际末轮的评估。

## 真实记录副本试跑

使用原记录最佳检查点、原 76 个训练工况与 24 个验证工况，追加 24 轮预算，CUDA 运行约 235 秒。所有训练发生在临时副本中，未改写原记录或样本。

| 自动恢复 | 轮数 | 学习率 | 权重衰减 | Dropout |
|---|---:|---:|---:|---:|
| 第 1 次 | 7 | 0.0005 | 0.0005 | 0.05 |
| 第 2 次 | 14 | 0.00025 | 0.0025 | 0.10 |
| 第 3 次 | 19 | 0.000125 | 0.01 | 0.15 |

最终在总第 25 轮达到本次轮数上限，自动恢复最佳权重。最佳验证损失从原记录的 0.16997 改善到 0.16213。逐张量比较最终网络和最佳检查点完全一致。

该单次试跑验证自动控制和收尾流程，并不保证对所有几何、种子或数据集都有同样精度提升，也不等于有限元误差认证。原始结果见 `ml-automatic-training-benchmark.json`。

复现（分支根目录，用本机存在的记录 ID）：

```powershell
python_machine_learning/.venv/Scripts/python.exe scripts/benchmark-automatic-training.py --run <记录ID> --epochs 24 --output docs/ml-automatic-training-benchmark.json
```

该脚本在临时目录复制训练图、元数据及指定模型，结束后只保留 JSON 报告。

回归验证：86 项 Python 测试、完整 JavaScript 测试集通过。新增覆盖自动降率/恢复/停止、过拟合持续性判断、正则化调整、恢复后基线保留、同数据切换策略保留最佳点、暂停重启后随机轨迹和恢复次数一致，以及无独立验证集时禁用自动选择。

## 操作

重启程序后，选择现有训练记录，保留原训练/验证数据勾选，直接点击“继续训练”。旧流程已经早停的记录，会先从原最佳点降低当前实际学习率再尝试。无需再次手动恢复最佳点，也无需为了使用自动控制重新训练网络结构。

默认开启自适应策略，恢复次数上限为 3；其他参数可沿用原值。需要保留固定轮数时可将早停设为 0。
