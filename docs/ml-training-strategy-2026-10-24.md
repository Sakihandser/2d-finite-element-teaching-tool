# 批量图训练、物理对称增强与持续训练（2026-10-24）

## 已实现的策略

### 不相连图的小批量训练

默认每批最多 4 张图、12,000 个输入单元；单图超过预算时单独训练。为细图节点、空间池和两级边分别偏移编号，模型一次处理多个互不相连的子图。没有填充，也不会在不同工况之间传消息。

单元面积与局部细化重要性在每张图内部归一化；邻边损失也在每张图内部归一化，再应用原有的几何/工况权重。合批损失等于这一批逐图加权损失的平均。细网格不会因为单元更多而直接压过粗网格。

实现参考 [PyG Advanced Mini-Batching](https://pytorch-geometric.readthedocs.io/en/latest/advanced/batching.html) 的不相连子图方法，使用现有 PyTorch 实现，不新增 PyG 依赖。一次优化更新现在可学习多张图；原有 `step`、累计学习次数仍统计图数，新增 `optimizerSteps` 单独统计本版实际更新次数。

### 保持物理一致的训练增强

从 90° 旋转和镜像构成的 8 种平面变换中随机选择。同步变换归一化位置、点力场、邻近载荷位移、分布力场、体力、边的相对位置；转动 90°/270° 时交换宽高。材料、距离、精度条件及标量目标尺寸保持不变，拓扑和空间池保留。

这利用了当前各向同性线弹性模型的对称性。只变换坐标而不变换载荷是错误的。增强只用于优化，不修改磁盘/缓存张量，不改变原始验证集，也不算作新增工况。新训练默认从 0.05 的隐藏特征 Dropout 开始；已有权重保持保存的 Dropout 设置。未来若加入各向异性材料或方向性支撑特征，需要同时扩展变换规则或关闭此增强。

### 持续训练到手动暂停

界面默认勾选“持续训练到手动暂停”。开启后，轮数是每段训练的预算；持续过拟合、平台期和预算结束会启动后续周期，而不是因为早停或 3 次恢复上限结束。

周期内采用余弦学习率；后续周期从全程最佳独立验证模型恢复，清空旧 AdamW 动量，并循环尝试配置学习率的 0.25、0.10、0.05 倍作为保守峰值，不低于学习率下限。过拟合触发时沿用正则化加强逻辑。最佳验证检查点跨周期保留，总轮数、学习图数及已学习几何历史不回退。没有可信独立验证集时，不据验证指标选择权重或判断过拟合，仍按轮数预算进入后续周期。

方法受 [SGDR: Stochastic Gradient Descent with Warm Restarts](https://arxiv.org/abs/1608.03983) 启发。这里使用 AdamW、最佳模型回退及保守峰值，是适配当前任务的实现，不是原论文算法或效果的复现。持续模式不会承诺验证误差一直下降，也不会在停滞后产生新几何。

取消持续模式后，仍保留原有有限轮数、恢复次数与早停机制。直接调用 API 时 `continuousTraining` 默认关闭，须明确提交 `true`；界面会明确传递所选模式。旧记录可直接继续，不要求重建网络或重新导入数据。

### 进程级无人值守恢复

同时启用持续模式与夜间保护时，Node 主服务记录当前训练意图。Python 进程意外退出后，最多重启 3 次，递增等待，并从完整检查点的原数据选择、读取位置和策略接续；不会重新导入、另建任务或追加额外轮数。每次启动训练前持久化运行意图，覆盖首次定时保存之前就退出的情况。

人工暂停立即取消重启意图；完成、人工暂停和不可用检查点均不会被当作正常训练重启。启动器退出时关闭旧协议输入，避免残留解释器继续占用锁；因服务连接中断而保存的暂停状态与人工暂停分开标记。重启预算耗尽显示具体错误。原有数值异常/OOM 恢复预算仍是 2 次，不能混同于进程重启次数。

主 Node 服务本身被关闭、电脑关机或断电后，本次不会自动启动 Windows 服务。尚未成功写入检查点的步骤仍可能丢失。永久坏数据、磁盘故障等仍会明确停止，不无限重试。

## 可复现基准 / Reproducible benchmarks

`scripts/benchmark-training-recipe.py` 可以在临时副本中比较逐图、合批与增强策略。需要自行提供本地记录 ID；报告、训练数据及模型检查点不随本次发行上传。速度和验证损失取决于数据及硬件，不承诺泛化精度或实际有限元误差改善。

The benchmark script compares training recipes in disposable copies. Supply your own local run ID. Local reports, datasets and checkpoints are excluded from this release. Timing and validation loss depend on data and hardware and do not certify finite element accuracy.

## 验证与使用

101 项 Python 测试、142 项完整 JavaScript 回归及 1 项真实进程终止/自动接续集成测试通过。新增验证包括：两版网络合批预测、损失、梯度与逐图一致；跨图节点/粗池隔离；变换后重建物理特征一致；缓存不变；单元预算；增强、Dropout 及余弦周期暂停恢复轨迹一致；跨多周期继续与人工暂停；进程恢复次数上限、暂停时取消重启。真实进程测试只使用临时数据目录。

重启主程序以加载新的 Node 桥接和 Python 代码。进入训练页，选择已有记录与当前数据，保留“持续训练到手动暂停”“夜间无人值守保护”及增强，使用 4 图/批、12,000 单元预算，点击“继续训练”。暂停以“已暂停”和新保存时间为准。若需要严格限定轮数，取消持续模式。

本地页面已检查新增选项布局；中英文翻译同步补齐。没有新增环境依赖。

## 文献取舍

[AMBER](https://arxiv.org/abs/2406.14161) 将网格尺寸场学习与中间网格的在线数据获取结合，适合当前任务的整体方向。本次保留现有尺寸场监督，改进训练执行与控制；尚未实现基于模型 rollout 的在线中间网格采集，旋转/镜像增强不能替代这些数据，也不能替代新增基础几何。

没有默认随机删除有限元邻接边。近期 [Effects of Dropout on Performance in Long-range Graph Learning Tasks](https://arxiv.org/abs/2502.07364) 指出 DropEdge 类方法可能削弱远距离节点的敏感性。对结构载荷/支撑传播，这是一项需要专门验证的风险；这里采用不改变拓扑的物理对称增强。这个取舍是针对当前结构的工程判断，并非上述论文直接验证了本模型。
