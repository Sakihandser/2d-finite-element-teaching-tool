## 几何和边界

- 整体为 600 × 600 mm 平板截面，坐标范围 −0.3～0.3 m，炮孔中心位于原点。
- 炮孔半径 8 mm，装药半径 5 mm，径向空气间隙 3 mm。
- 青砂岩夹层宽 54 mm，两端半圆半径 27 mm。图 4.1 的 300 mm 标注按两圆端中心之间的直线段长度解释，总长为 354 mm。
- W45/W90 的夹层中心与炮孔重合。H45/H90 中，孔心至夹层近侧直边的距离为 120 mm，因此夹层轴线距孔心为 147 mm。
- 两种岩石采用共享节点的共形界面，孔内不划岩体 TRI3 单元，空气和已反应产物由内部径向气体网格求解。数值模型不另设粘结过渡层。
- 四个 JSON 均以无围压为初始工况；四周吸收边界，先静力平衡后保持外载荷。论文其余围压可在爆破设置中改成水平/竖直 20/20、10/5、5/10 MPa，并分别保存为新 JSON。

几何来源为论文图 4.1（PDF 第 122 页、印刷页 108）、图 4.11（PDF 第 136 页、印刷页 122）。四种命名及围压来自第 4.1.4 节（PDF 第 124–125 页）。

## 当前能算到的范围

**这是二维弹性与拉伸损伤演示，尚不能完整复现论文中的三维 MPM + JH2 破碎和裂纹结果。** 当前程序没有 JH2 的应变率强化、压力相关强度、塑性、压碎和三维 CPDI/GIMP 粒子算法，因此没有把这些参数伪装成已启用的计算功能。

模型现默认启用拉伸损伤。经用户选择，花岗岩单轴抗拉强度设为 8 MPa、青砂岩 4 MPa，断裂能 Gf=100 J/m²：这些是明确标注的、未经实验标定的演示值，仅用于跑通当前拉伸损伤功能。材料库与四个模型文件已同步，可在“时间积分与损伤”或材料库修改。抗压强度仍留空。JH2 的静水拉伸强度 T=54/44 MPa 不是单轴抗拉强度，不能直接当作现有拉伸损伤阈值；也没有采用参数图中的 MAT_PLASTIC_KINEMATIC 岩石卡替代论文的两种材料。

默认时长 0.2 ms、自动时间步、101 帧、192 个气体单元、600 秒运行上限。模型按当前程序的单位厚度计算，不能直接把单位深度能量当作物理试件的总能量。默认岩体布点间距 5 mm，孔壁约 48 条边；这是可运行的初始网格，不等同于论文的 1.5 mm MPM 背景网格，也未声称所有波形、尖峰或损伤结果已收敛。

已验证 W45-0-0/PETN 完整 0.2 ms 运行：约 4995 个岩体步，自动步长约 0.04004 μs，全部气体状态有限，气体能量相对误差约 2×10⁻¹⁵。完成计算仅说明模型和数值通道可运行，不是论文实验结果复现的证明。

离线重建脚本为 scripts/build-thesis-blast-models.cjs，再运行 scripts/finalize-thesis-models.cjs；两者不会在网页中加载。manifest.json 保存模型网格清单、几何定义和原始参数供核对。

损伤通道验证：W45 / PETN / 0.2 ms / 101 帧 / 自动时间步 / Gf=100 J/m²，4995 步完成（约 27.4 秒，不含浏览器导入与导出开销）；全部应力及损伤历史有限，损伤不可逆，最终 35082/35110 个单元 d>0.01，最大 d≈1。当前演示参数下损伤几乎遍及全板，说明结果对阈值和本构选择非常敏感，不能将此分布当作论文试验裂纹形态。当前网格对 Gf 的下界约为花岗岩 3.710、青砂岩 1.736 J/m²；实际计算始终要求 Gf 严格大于各单元下界。验证脚本为 scripts/verify-thesis-damage.cjs。
